# Introduction

Lumen consists of a compiler collection and virtual machine.

- **The Lumen Compiler Collection (LCC)** provides necessary development tools to compile
  C-compatible code for virtual machine.

- **The Lumen Virtual Machine (LVM)** provides the environment for learning the operating system
  development and experimentation.

All these components are written and developed in Golang. The `docs/` folder provides a comprehensive treatment
of LCC and LVM.
